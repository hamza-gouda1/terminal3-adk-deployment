# Security policy

Report vulnerabilities privately by email to **Hamza Gouda <hraafat357@gmail.com>** or through
[GitHub private reporting](https://github.com/hamza-gouda1/terminal3-adk-deployment/security/advisories/new).
Do not open a public issue for a security report.

This repository is a bounty submission. The contract has not been audited and has only been run on the
Terminal3 testnet. Do not use it to protect real funds. Never commit a real `T3N_API_KEY`; `.env` is git-ignored.
